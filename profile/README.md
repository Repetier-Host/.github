# Repetier-Host - Talk To A Printer You Already Operate

## Before and After Repetier-Host

**Before Repetier-Host**  
The printer waits, the model is in another window, and you cannot tell which file is about to move.

**After Repetier-Host**  
One plate in Repetier-Host, a printer you already run, and a job you can still name tomorrow.

This contrast is the easiest way to explain Repetier-Host: the file on the plate is the file you meant to send.

---

## Why This Exists

Most print jobs split the model, the connection, and the log across tools you then forget. **Repetier-Host** keeps the printer you operate and the part you may print on one host.

Repetier-Host solves **one specific problem**: sending a job you can still explain. Open the file, look at the plate, talk to the machine on this desk, and leave the project where you named it.

If you are tired of guessing which gcode belongs to which part, **Repetier-Host** is for you.

A second sitting should reopen the same job. The port should still be the printer you own. Unused files should not sit in the live list.

Repetier-Host should still show the same plate after you reconnect. If the port drifted, stop and pick the printer you actually run. Keep the job next to the model so the next print is not a guess.

---

## Quick Start with Repetier-Host

1. **Open Repetier-Host** - On the PC that already reaches the printer.
2. **Load the part** - Use a model you are allowed to print.
3. **Check the plate** - Confirm orientation before you heat anything.
4. **Connect** - Talk only to the machine you operate.
5. **Send the job** - Watch the first layer instead of walking away.
6. **Save the project** - Keep it beside the model in the folder you named.
7. **Disconnect** - Leave the printer in a state the next person can understand.

---

## Closing Notes for Repetier-Host

Treat Repetier-Host as the host for one printer you run, not as a mailbox for every file on the disk. Open it when the job is the one you meant. Keep the queue short. Move finished gcode out of the working folder. Let old tests stay quiet.

If you change desks, confirm the port before you send heat. If you show a teammate Repetier-Host, show them the plate and the printer name. After that, Repetier-Host usually needs almost no explanation.

## Requirements for Repetier-Host

| | Minimum | Recommended |
|-|---------|--------------|
| OS | Windows 10 | Windows 11 |
| CPU | Dual-core | Modern multi-core |
| RAM | 4 GB | 8 GB or more |
| Printer | A printer you operate | A stable link to that machine |

Use Repetier-Host only with a printer you are allowed to run. Keep jobs in a folder you already documented. Do not point the host at a machine you do not own or were not asked to use.
